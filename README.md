# Группировка вкладок по сайту (Firefox)

Расширение группирует вкладки Firefox по сайту, используя **встроенные группы
вкладок Firefox** (WebExtensions API `tabGroups`, доступен с Firefox 139;
манифест требует Firefox **142+** из-за обязательной декларации о сборе
данных).

Интерфейс полностью на русском и английском — язык подхватывается
автоматически из языка интерфейса Firefox (см. раздел «Локализация» ниже).

## Что оно делает

- **Автоматически** группирует вкладку с другими вкладками того же сайта,
  как только она закончила загружаться. Работает, если на сайте уже открыта
  хотя бы ещё одна вкладка — группа из одной вкладки не создаётся. Можно
  выключить на странице настроек.
- Группа получает название = домен сайта (например, `github.com`) и
  стабильный цвет — один и тот же сайт всегда получает один и тот же цвет.
- **Кнопка на панели инструментов** — клик сразу группирует **все** вкладки
  текущего окна по сайтам (полезно, если автогруппировка выключена или
  нужно разом привести в порядок уже открытые вкладки). Работает независимо
  от настройки автогруппировки.
- **Контекстное меню**:
  - «Сгруппировать вкладки по сайтам» — на странице, на вкладке (правый клик
    по вкладке в полосе вкладок) и на кнопке расширения; делает то же самое,
    что и клик по кнопке.
  - «Настройки…» на кнопке расширения — открывает страницу настроек.
- **Список исключений** — сайты, которые никогда не группируются, ни
  автоматически, ни вручную. Управляется на странице настроек.
- **Страница настроек** (открывается через `about:addons` → шестерёнка у
  расширения → «Настройки», либо через контекстное меню на кнопке
  расширения): переключатель автогруппировки и список исключений с полем
  добавления и кнопками удаления. Изменения сохраняются сразу, без кнопки
  «Сохранить».

## Сделанные допущения

- **«Один сайт» = полный hostname** (например, `mail.google.com` и
  `docs.google.com` — разные сайты, разные группы), а не домен верхнего
  уровня. Префикс `www.` игнорируется — `www.example.com` и `example.com`
  считаются одним сайтом. Это касается и списка исключений: добавляя
  `example.com`, вы исключаете именно этот hostname (для поддоменов вроде
  `shop.example.com` исключение нужно добавить отдельно).
- Закреплённые (pinned) вкладки в группировку не попадают — `tabs.group`
  сам их откалывает от закрепления, и это может быть неожиданно, поэтому
  они пропускаются намеренно.
- Функция «закрывать вкладки по имени сайта» из первоначального описания
  проекта в это расширение не включена — сейчас оно только группирует.

## Локализация

Строки интерфейса (название, кнопка, контекстное меню, страница настроек)
лежат в `_locales/ru/messages.json` и `_locales/en/messages.json` — это
стандартный механизм локализации WebExtensions. Firefox сам выбирает нужный
файл по языку интерфейса браузера; если языка нет в списке — используется
русский (`default_locale` в манифесте). Чтобы добавить ещё один язык,
достаточно скопировать один из файлов `messages.json` в новую папку вида
`_locales/<код_языка>/` и перевести значения `message`.

## Установка

Firefox не даёт ставить неподписанные расширения насовсем — есть два пути.

### Быстрый способ — временная установка (для тестирования)

1. Откройте `about:debugging#/runtime/this-firefox` в Firefox.
2. Нажмите «Загрузить временное дополнение…» (Load Temporary Add-on).
3. Выберите файл `tab-site-grouper.zip`.
4. Иконка появится на панели инструментов.

Дополнение будет работать, пока не перезапустите Firefox — после перезапуска
шаги 1–3 нужно повторить.

### Постоянная установка — подпись через addons.mozilla.org

Для постоянной установки Mozilla должна подписать расширение (даже если вы
не собираетесь публиковать его в каталоге — есть режим «unlisted»,
подписание происходит автоматически, без ручной модерации). Шаги:

1. Зайдите на https://addons.mozilla.org/ и войдите (или создайте бесплатный
   аккаунт Firefox).
2. Откройте страницу управления API-ключами разработчика:
   https://addons.mozilla.org/developers/addon/api/key/ — сгенерируйте пару
   `JWT issuer` (это и есть API key) и `JWT secret` (API secret). Эти ключи
   можно в любой момент отозвать и создать заново в том же интерфейсе.
3. Установите инструмент `web-ext` (если ещё не установлен):
   `npm install -g web-ext`
4. В папке с расширением выполните:
   ```
   web-ext sign --channel=unlisted \
     --api-key=<ваш JWT issuer> \
     --api-secret=<ваш JWT secret>
   ```
   Команда загрузит расширение на сервер Mozilla, дождётся автоматической
   проверки (обычно 1–5 минут) и сохранит подписанный `.xpi` в папку
   `web-ext-artifacts/`.
5. Откройте полученный `.xpi` в Firefox (перетащите файл в окно браузера,
   либо `about:addons` → шестерёнка → «Установить дополнение из файла…») —
   он установится насовсем и переживёт перезапуск браузера.

При обновлении версии (`version` в `manifest.json`) шаг 4 нужно повторить —
каждая подписанная версия хранится в вашем аккаунте разработчика отдельно.

## Проверка минимальной версии Firefox

Расширение использует `browser.tabs.group` / `browser.tabGroups`, которых
не было в старых версиях Firefox. При старте расширение проверяет их
наличие и, если API нет, ничего не делает и пишет предупреждение в консоль
расширения (видно там же, в `about:debugging`, кнопка «Инспектировать»).

## Файлы

- `manifest.json` — манифест расширения (Manifest V3, Firefox-only).
- `common.js` — общая логика (определение хоста, валидация, цвет группы),
  используется и фоновым скриптом, и страницей настроек.
- `background.js` — автогруппировка, кнопка, контекстное меню.
- `options/` — страница настроек (`options.html`, `options.css`, `options.js`).
- `_locales/ru/`, `_locales/en/` — переводы интерфейса.
- `icons/` — иконки панели инструментов (сгенерированы `make_icons.py`).
- `make_icons.py` — скрипт генерации иконок (нужен только для правки дизайна).
